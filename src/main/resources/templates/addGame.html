Edit Titles

Welcome to your Edit Game Title page:

Add a New Game Title

Enter the Game name, and optionally the number of players, then click Add Game to Database.







Edit an Existing Game Title

To edit an existing game title, select what game title you wish to edit, then enter the new information.









If you edit a game or the information assocaited with it, it will be changed for all of your games that refrence it

Remove Game

Removing a game will remove it from your list of available games. You cannot remove a game while it is associated with any of your collection entries. Remove those entries first if you want to remove the game.
