# Gameathon

A web application for managing a personal collection of games built using the Spring framework in Java.

---

## What is it?

Gameathon is a web application that allows users to keep track of the games they own in a convenient way. It allows 
users to join and create families so that users can also easily view what games their family already has.

---

# How to Run Gameathon

## Requirements
- Java JDK 25 installed
- Git installed

To Check Java version:
```
java -version
```

---

### Mac / Linux

1. Clone the repo
```
git clone https://github.com/Stormfire-CS/Gameathon.git
cd Gameathon
```
2. Create the output folder
```
mkdir out
```
3. Compile all Java files
```
javac -d out src/**/*.java
```
4. Run the game
```
java -cp out  edu.carroll.cs341.GameathonApplication
```
